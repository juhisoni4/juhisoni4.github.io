# Juhi Soni — GitHub Pages Portfolio

## Files

- `index.html` — main website
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation
- `assets/Juhi_Soni_CV.pdf` — add your CV PDF here

## Before publishing

Search `index.html` for:
- `[ADD YOUR PAPER TITLE HERE]`
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`
- `href="#"` project/paper links

Replace those placeholders with your real information.

## Publish with GitHub Pages

1. Create a GitHub repository named `<your-username>.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under the Pages/build settings, select **Deploy from a branch**, choose your main branch and `/ (root)`.
5. Save and wait for the GitHub Pages deployment.
6. Your site will be available at `https://<your-username>.github.io/`.

You can later connect a custom domain.
